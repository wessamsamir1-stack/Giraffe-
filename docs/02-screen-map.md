## ١. بنية التنقل — Navigation structure

```
Giraffe
│
├── Splash
├── Onboarding Flow          (مرة واحدة فقط)
├── Auth Flow                (للزائر)
│
└── Main Shell               (٥ تبويبات ثابتة أسفل الشاشة)
    ├── Market               ← التبويب الافتراضي — السوق المفتوح
    ├── Deck                 ← السحب
    ├── Matches
    ├── My Items
    └── Profile
```

### ليه بقت ٥ بدل ٤

الاعتراض الوحيد الجدّي على واجهة السحب المجردة إنها **بتخفي المخزون** — المستخدم اللي عارف هو عايز إيه بالظبط بيتحبس في سحب عشوائي.

السوق المفتوح بيحل ده، والاتنين مكمّلين لبعض:

| التبويب | الغرض |
|---|---|
| **السوق** | البحث المقصود — المستخدم عارف هو عايز إيه |
| **اسحب** | الاكتشاف — المستخدم مش عارف هو عايز إيه |

السحب لوحده بيخفي المخزون، والسوق لوحده بيحوّلنا لموقع إعلانات مبوبة عادي زي أي موقع تاني.

في الوضع العربي التبويبات بتتقلب من اليمين لليسار تلقائياً.

## ٤. الإعداد الأولي — First-run setup

المسار ده **إجباري** ومفيش منه خروج، لأن من غيره محرك المطابقة ما بيشتغلش.

### 4.1 — Profile basics

`/onboarding/profile`

اسم العرض · اسم المستخدم · صورة شخصية (اختيارية)

### 4.2 — Location

`/onboarding/location`

اختيار المحافظة والمنطقة من قائمة.

مش بناخد إحداثيات دقيقة — منطقة تقريبية بس، للخصوصية.

### 4.3 — Wishlist builder ⭐

`/onboarding/wishlist`

**أهم شاشة في التطبيق كله.**

- شبكة تصنيفات بأيقونات كبيرة
- المستخدم يختار **٣ على الأقل**
- لكل اختيار: كلمة بحث حرة اختيارية + حد أقصى للقيمة اختياري
- شريط تقدم واضح: `2 / 3`
- زر المتابعة مقفول لحد ما يوصل ٣

مفيش تخطي هنا. لو المستخدم عدّى من غير wishlist، الـ deck هيبقى فاضي أو عشوائي، وده معناه إنه هيمسح التطبيق.

### 4.4 — First item upload

`/onboarding/first-item`

نفس تدفق رفع المنتج العادي، بس بنص تحفيزي مختلف.

مسموح بالتخطي — بس بنوضح إن من غير منتج واحد على الأقل مش هيقدر يعمل ماتش.

## ٥. التبويب الأول: السوق المفتوح — Market

### 5.0.1 — Market

`/market`

الشاشة الافتراضية بعد الدخول.

**المحتوى بالترتيب:**

- ترويسة فيها المدينة الحالية وزر الإشعارات
- شريط بحث بلغة طبيعية
- شريط الأقسام المميزة (٨ أقسام + "كل الأقسام")
- **من قائمة رغباتك** — منتجات مطابقة لرغباتك ظهرت حديثاً
- **خدمات مقابل خدمات** — القسم الجديد
- **أحدث المنتجات** — شبكة عمودين

### 5.0.2 — All categories

`/market/categories`

٢١ قسم رئيسي، كل واحد بيتفتح على أقسامه الفرعية.

القسمان المقيّدان (مواد بناء · حيوانات) بيظهر فيهما تنبيه بالشروط القانونية قبل النشر.

### 5.0.3 — Category

`/market/category/:id`

شرائح الأقسام الفرعية · عدد النتائج · ٥ طرق ترتيب · شبكة المنتجات · حالة فاضية بزر إضافة منتج.

### 5.0.4 — Search

`/market/search`

بحث بلغة طبيعية.

الفلاتر اللي فهمها النموذج بتظهر **فوق النتائج وقابلة للتعديل** — مش صندوق أسود.

مثال: "عايز لابتوب ألعاب بأقل من 30 ألف في القاهرة" بتتحول لـ

`كمبيوتر ولابتوب` + `أقل من 30,000` + `القاهرة`

## ٥.١. التبويب الثاني: السحب — Deck

### 5.1 — Deck

`/deck`

قلب التطبيق.

**الكارت:**

```
┌─────────────────────────────┐
│                             │
│      صورة المنتج المعروض      │
│                             │
│  ┌───────────────────────┐  │
│  │  توافق  87%           │  │
│  └───────────────────────┘  │
├─────────────────────────────┤
│  iPhone 15 · حالة ممتازة     │
│  أحمد · موثوق · 4.8 ★        │
│  السالمية · 3 كم             │
├─────────────────────────────┤
│  مقابل:  PlayStation 5      │
│          + 30 KD منك         │
└─────────────────────────────┘
```

**الحركات:**

| الحركة | النتيجة |
|---|---|
| سحب لليسار | تخطي |
| سحب لليمين | مهتم |
| سحب لأعلى | صفقة أحلام |
| ضغطة على الكارت | فتح صفحة المنتج |
| ضغطة على اسم المالك | فتح الملف الشخصي |
| زر التراجع | إلغاء آخر سحبة |

**حالات الشاشة:**

| الحالة | المعروض |
|---|---|
| تحميل | كروت هيكلية |
| خلصت الكروت | "خلصنا حالياً — ضيف منتج جديد أو وسّع قائمة رغباتك" مع زرين |
| مفيش منتجات عندك | "ارفع أول منتج عشان نبدأ نجيبلك صفقات" |
| مفيش wishlist | "قولنا نفسك في إيه" |
| مفيش نت | "مفيش اتصال" مع زر إعادة محاولة |

الحالات دي مش تفاصيل — دي معظم ما هيشوفه المستخدم في الأسابيع الأولى قبل ما تكبر السيولة.

## ٦. التبويب الثالث: المقايضات — Matches

### 6.1 — Matches list

`/matches`

تبويبان فرعيان:

`نشطة` و `مؤرشفة`

كل صف: صورة الطرف التاني · آخر رسالة · حالة الصفقة · وقت

عداد الغرف النشطة ظاهر: `7 / 10`

### 6.2 — Trade room

`/matches/:matchId`

الشاشة الأكثر كثافة في التطبيق.

**من فوق:**

شريط بيوضح حالة الصفقة الحالية:

`تفاوض` → `عرض معلق` → `متفق` → `لقاء محدد` → `مكتملة`

**في المنتصف:**

الرسائل، وكروت العروض بتظهر جوه المحادثة كعناصر منظمة مش كنص.

**من تحت:**

حقل الكتابة · زر صورة · زر إنشاء عرض · زر تحديد لقاء

**قائمة الخيارات:**

كتم · حظر · بلاغ · أرشفة · طلب إغلاق الصفقة

`/matches/:matchId/offer/new`

## ١١. رحلة المستخدم الجديد — Golden path

الرحلة اللي كل قرار تصميم لازم يخدمها:

```
تحميل
  ↓
٣ شرائح تعريف            (٢٠ ثانية)
  ↓
تسجيل بجوجل              (١٠ ثواني)
  ↓
الاسم والمنطقة            (٣٠ ثانية)
  ↓
بناء قائمة الرغبات ⭐      (٦٠ ثانية)
  ↓
رفع أول منتج بالـ AI       (٩٠ ثانية)
  ↓
أول كارت صفقة مخصص        ← أول لحظة قيمة
  ↓
ماتش                     ← خلال ٢٤ ساعة (الهدف)
  ↓
تفاوض واتفاق
  ↓
لقاء آمن
  ↓
صفقة مكتملة              ← خلال ٧ أيام (الهدف)
```

**الوقت من التحميل لأول كارت مخصص: أقل من ٣ دقايق.**

الرقم ده هو المعيار. أي شاشة أو حقل بيزوّده لازم يتشال أو يتأجل.

## ١٢. قواعد التصميم المشتركة

- كل شاشة لازم يكون ليها ٤ حالات معرّفة: تحميل · فاضية · خطأ · نجاح
- مفيش شاشة بيضا فاضية أبداً — لازم رسالة وزر إجراء
- كل حركة مدمرة ليها تأكيد
- زر الرجوع في أندرويد لازم يشتغل صح في كل مسار
- التطبيق يفتح في أقل من ثانيتين
- كل الأنيميشن ٦٠ إطار في الثانية
- دعم كامل للاتجاهين

`RTL` و `LTR`

- الوضع الليلي من اليوم الأول مش مؤجل
