## الأسبوع ٤ — محرك المطابقة

**أهم أسبوع في المشروع كله.**

- استعلام ترشيح الصفقات بالشرط المزدوج
- حساب نسبة التوافق
- ترتيب النتائج
- تخزين نتائج السحب
- كشف الماتش المتبادل
- إنشاء الماتش تلقائياً
- المسافة بهافرساين على إحداثيات مزحزحة

- حدود السحب اليومية

**المخرج:** كارت صفقة حقيقي بيظهر، والماتش بيتكوّن لما الطرفين يوافقوا

**بوابة:** لو نسبة الماتش في الاختبار الداخلي أقل من ١٥٪، نوقف ونعيد ضبط المحرك قبل ما نكمل.

مش بننتقل للمرحلة التانية إلا لما:

- ١٠٠ صفقة مكتملة حقيقية على الأقل

**دي أهم قاعدة في الخطة كلها.**

معظم المشاريع بتموت لأنها بتضيف مميزات فوق أساس ما اشتغلش.

## ٢.١ — المقايضة الثلاثية ⭐

`3-Way Trades`

الحل الرياضي الوحيد لمشكلة توافق الرغبات المزدوج.

أحمد عايز اللي عند سارة · سارة عايزة اللي عند خالد · خالد عايز اللي عند أحمد

مفيش أي اتنين فيهم يقدروا يقايضوا مباشرة، بس التلاتة مع بعض ينفع.

- كشف الحلقات في الرسم البياني للرغبات
- غرفة مقايضة بثلاثة أطراف
- تأكيد ثلاثي
- لقاء مشترك أو تسلسلي

ده أكتر feature هيزوّد الصفقات، وعشان كده هو أول حاجة في المرحلة التانية.

## ٣.١ — الاشتراك المميز

`Giraffe Premium`

| الميزة | ملاحظة |
|---|---|
| سحبات غير محدودة | |
| شوف مين عمل لك إعجاب | |
| فلاتر متقدمة | |
| أولوية في المطابقة | |
| قائمة رغبات غير محدودة | |
| شارة مميز | |
| إحصائيات الملف الشخصي | |

**ملاحظة مهمة:**

ميزة "شوف مين عمل لك إعجاب" لازم تفضل **مجانية جزئياً** في البداية (مثلاً آخر ٣ إعجابات).

السبب: الهدف في السنة الأولى هو إتمام أكبر عدد صفقات مش تحقيق دخل. حجب الإعجابات بيقلل الصفقات وبالتالي بيقتل النمو.

الاشتراك لازم يمر عبر

`In-App Purchase`

بعمولة ٣٠٪ لآبل وجوجل.

# قواعد ثابتة على طول الخطة

1. **مفيش feature جديد قبل ما مؤشرات المرحلة الحالية تتحقق**
2. **كل feature لازم يكون مربوط بمؤشر بيتقاس**
3. **الأمان الجسدي أولوية قصوى مهما كان الوقت**
4. **لو المستخدم بيشتكي من قلة الكروت، الحل سيولة مش مميزات**
5. **الدخل مؤجل للسنة التانية — السنة الأولى للصفقات**
